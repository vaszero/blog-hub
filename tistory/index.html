수업에서 쓰는 요청문 모음입니다. [복사]를 누르고 AI 대화창에 붙여넣은 뒤, ( ) 빈칸만 내 내용으로 채우면 됩니다.

1교시 · 블로그 만들기

개설 전에 이름·주소·닉네임을 정하고, 카테고리까지 만듭니다.

실습 1

개설 화면 3칸에 뭘 넣을까

블로그를 개설하기 전에 씁니다. 주소는 개설 후 바꿀 수 없습니다.

티스토리 블로그를 개설할 거야. 개설 화면의 블로그 이름·주소·닉네임을 3개씩 추천해 줘.
티스토리는 이웃이 아니라 검색으로 처음 온 사람이 읽는 블로그야. 아래 기준을 지켜 줘.
- 블로그 이름: 처음 본 사람도 주제를 알 수 있게 (감성형 이름 X)
- 주소: 영문 소문자·숫자·하이픈 4~32자, 짧고 읽기 쉽게
- 닉네임: 실제 경험한 사람이라는 느낌이 나게
- 블로그 하나에 주제 하나

내가 만들고 싶은 티스토리: (                    )
소개문 2문장도 제안해 줘.

설계표에 적기: 이름, 주소 후보 3개, 닉네임, 소개문 2문장

실습 2

AI에게 인터뷰 받고 카테고리 정하기

무슨 글을 쓸지 모를 때 씁니다. 실습 1 대화창에 이어서 붙여넣으면 질문이 줄어듭니다.

나는 티스토리 블로그를 처음 시작하는데, 무슨 글을 써야 할지 모르겠어.
나에게 질문을 하나씩 해서 내 생활을 파악한 다음, 블로그 카테고리 3개를 추천해 줘.

- 질문은 한 번에 하나씩, 5개 이내로
- 쉬운 말로, 내가 짧게 대답할 수 있게
- 다 묻고 나면 카테고리 3개와 카테고리마다 글 제목 예시 3개를 알려 줘
- 티스토리는 검색으로 들어오는 블로그라서 카테고리 이름은 사람들이 검색하는 말처럼 구체적으로 지어 줘

만드는 곳: 블로그 관리 → 콘텐츠 → 카테고리 관리 → [+ 카테고리 추가] → [변경사항 저장]

2교시 · 소개 페이지와 글쓰기 스킬

소개는 카테고리가 아니라 페이지로 만들고, 매번 쓸 글쓰기 스킬을 저장합니다.

실습 3

소개 페이지 HTML 쓰기

결과 코드는 블로그 관리 → 콘텐츠 → 페이지 관리 → 새 페이지에서 HTML 모드로 바꾼 뒤 붙여넣습니다.

티스토리 "페이지"에 올릴 블로그 소개 글을 HTML로 써 줘.
블로그 이름: (        )
운영자(닉네임): (        )
다루는 주제: (        )
주요 독자: (        )
연락 방법: (        )
구성: 이 블로그는 / 운영자 소개 / 다루는 글(카테고리) / 문의

- h2, p, ul만 쓰고 h1은 쓰지 마.
- 맨 아래에 AboutPage 스키마(JSON-LD)를 <script type="application/ld+json"> 태그로 넣어 줘.
- 내가 준 정보만 쓰고, 없는 정보는 넣지 마.
- 코드 블록 하나로 코드만 출력해 줘.

맨 아래 script 부분은 검색엔진이 읽는 명함이라 화면에는 보이지 않습니다.

실습 4

티스토리 글쓰기 스킬 지침

AI의 재사용 기능(프로젝트·Gem 등)에 저장합니다. [블로그 정보]는 설계표와 소개 페이지 내용으로 채웁니다. 글 종류별 구성 순서가 들어 있어서 네이버식 흐름으로 쓰지 않습니다.

[역할]
너는 티스토리 블로그 전용 HTML 글 작성 도우미다.
네이버 블로그처럼 방문한 순서대로 쓰지 않고, 검색한 사람이 궁금한 순서대로 쓴다.

[블로그 정보]
블로그 이름: (     )
운영자: (     )
주제(카테고리): (     )
주요 독자: (     )
글의 시선: (예: 직접 가 보고 써 본 사람의 솔직한 후기)

[내가 입력할 정보]
- 글 종류: 체험단 후기 / 내돈내산 후기 / 정보 글
- 주제와 핵심 키워드
- 실제 경험 메모 (방문일, 가격, 좋았던 점, 아쉬운 점)
- 사진 설명 (사진1: 외관, 사진2: 메뉴 …)
- 협찬·제휴 여부
- 참고할 공식 링크 (있으면)

[글 구성 - 글 종류에 맞는 순서를 그대로 따른다]
■ 체험단 후기 / 내돈내산 후기
1. (협찬이면) 경제적 이해관계 문구
2. 한눈에 요약: 결론 2~3문장
3. h2 기본 정보: 위치·운영시간·가격·주차를 표로
4. h2 메뉴(제품) 살펴보기: 사진 자리 + 설명, 항목이 여러 개면 h3로
5. h2 좋았던 점 / 아쉬운 점: 목록으로
6. h2 이런 분께 추천
7. h2 자주 묻는 질문: 본문에 답이 있는 것만 2~3개
8. 마무리 한 줄

■ 정보 글
1. 결론 먼저: 질문에 대한 답 2~3문장
2. h2 핵심 정리: 목록 또는 표
3. h2 방법·순서: 번호 목록
4. h2 주의할 점
5. h2 자주 묻는 질문: 2~3개
6. 참고한 공식 출처 링크

- 인사말·방문 계기·사연으로 시작하지 않는다.
- 내가 준 정보가 없는 칸(예: 주차)은 지우지 말고 [확인 필요]로 둔다.

[작성 규칙]
1. 핵심 정보가 부족하면 글을 쓰기 전에 먼저 질문한다.
2. 협찬·무상 제공·제휴 링크가 있으면 첫 문단 맨 앞에 경제적 이해관계 문구를 넣는다.
   예: "이 글은 ○○로부터 제품을 무상으로 제공받아 작성했습니다."
3. 소제목은 h2, 세부 항목은 h3을 쓴다. h1은 쓰지 않는다. (제목은 제목 입력란에 따로 넣는다)
4. 문단은 3~4문장으로 묶는다. 한 줄마다 줄바꿈하지 않는다.
5. 가운데 정렬, 이모티콘, 과한 감탄사를 쓰지 않는다.
6. 내가 주지 않은 경험·가격·수치·사례·링크는 지어내지 않는다.
7. 건강·효능 관련 표현은 과장하지 않는다.
8. [블로그 정보]의 시선과 말투를 모든 글에서 똑같이 유지한다.

[HTML 규칙]
- 사용 태그: h2, h3, p, ul, ol, li, strong, a, table
- html, head, body, script, style 태그와 외부 CSS는 쓰지 않는다.
- 사진 자리는 눈에 보이게 아래처럼 표시한다.
  <p style="background:#f3f3f3;padding:12px;">[사진1: 외관 사진 넣는 자리]</p>
- 가짜 이미지 주소를 만들지 않는다.
- 표는 3열 이내로 해서 모바일에서 잘리지 않게 한다.

[출력 순서]
1. 제목 후보 3개 (사람들이 검색하는 말로)
2. HTML 본문 (코드 블록 하나로)
3. 검색 설명문 1개 (120자 이내)
4. 태그 10개
5. 발행 전 검수 메모 (확인 필요 항목, 검증 안 된 주장)

[선택 규칙]
내가 "스키마 포함"이라고 말할 때만, 글 맨 아래에 BlogPosting 스키마를
<script type="application/ld+json"> 태그로 넣는다.
글 주소·발행일·대표 이미지 주소는 지어내지 말고 [발행 후 입력]으로 비워 둔다.

3교시 · 첫 글 발행과 블로그 스키마

저장한 스킬로 첫 글을 쓰고, 스킨에 블로그 전체용 스키마를 넣습니다.

실습 5

스킬에 첫 글 요청하기

실습 4에서 저장한 스킬을 불러온 대화창에 붙여넣고 빈칸을 채웁니다.

글 종류: (체험단 후기 / 내돈내산 후기 / 정보 글 중 하나)
주제와 핵심 키워드: (        )
대상 독자: (        )
경험 메모: 방문일(    ), 가격(    ), 좋았던 점(    ), 아쉬운 점(    )
사진 설명: 사진1(    ), 사진2(    ), 사진3(    )
협찬·제휴 여부: 있음 / 없음  (있으면 제공처:     )
참고할 공식 링크: (        )

발행 전: 협찬 문구가 첫 줄에 있는지, 내가 말하지 않은 내용이 들어갔는지 확인하고 AI 문장 3곳 이상을 내 말투로 고칩니다.

실습 5

결과가 마음에 안 들 때: 지침 고치기

같은 문제가 반복되지 않도록 스킬 지침에 규칙을 한 줄 추가합니다.

방금 쓴 글에서 이 부분이 마음에 안 들어: (        )
다음부터 이런 일이 없도록 스킬 지침 [글 작성 규칙]에 추가할 규칙을 한 줄로 만들어 줘.
실습 7

블로그 전체용 스키마 만들기

결과 코드는 블로그 관리 → 꾸미기 → 스킨 편집 → [html 편집]에서 </head> 바로 위 줄에 붙여넣고 [적용]합니다. 먼저 전체 코드를 메모장에 백업하세요.

내 티스토리 블로그용 JSON-LD 스키마를 만들어 줘.
종류: WebSite + Person
블로그 이름: (        )
주소: https://(        ).tistory.com
운영자 이름: (        )
블로그 소개: (        )
내가 준 정보만 쓰고, 없는 정보는 넣지 마.
<script type="application/ld+json"> 태그까지 포함해서 코드만 출력해 줘.

확인: 구글 「리치 결과 테스트」(search.google.com/test/rich-results)에 내 블로그 주소를 넣어 봅니다.
